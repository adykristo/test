# Fitur Tryout KlinikFisikapku Terintegrasi

- Editor admin privat dengan tema ungu–pink dan koneksi GitHub + Apps Script.
- Jenjang SD, SMP, dan SMA.
- PG4, PG5, PGK MCMA, PGK kategori, isian singkat, dan esai.
- Skor objektif penuh/sebagian untuk PGK.
- Upload gambar pada narasi, opsi, pernyataan PGK, kunci/pedoman, dan pembahasan.
- Import massal `.docx`; Equation Word otomatis dirender menjadi PNG.
- Kunci baru disimpan privat pada Apps Script, bukan paket JSON peserta.
- Preview sebagai siswa, LaTeX, autosave, timer, navigator, dan tanda ragu.
- Data paket lama tetap kompatibel dan dapat dimigrasikan dengan simpan ulang.

Gunakan `admin-dashboard-login.html`, bukan `admin.html`. Instalasi lengkap ada
di `PANDUAN-INTEGRASI-ADMIN-TRYOUT.md`.
