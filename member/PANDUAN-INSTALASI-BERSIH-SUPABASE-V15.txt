KLINIKFISIKAPKU V15 — URUTAN INSTALASI BERSIH

PENTING
- Jangan jalankan patch SQL lama.
- Jangan taruh service_role/secret key di browser.
- Pembuat Soal V12 tidak diubah.

1. BUAT / PILIH PROJECT SUPABASE YANG AKTIF
   Salin Project URL dan Publishable/anon public key langsung dari Dashboard.
   Jika hostname memberi NXDOMAIN, periksa project ref, status paused/deleted, dan jaringan/DNS sebelum menyentuh frontend.

2. ISI member/supabase-config.js
   - url = Project URL
   - anonKey = Publishable/anon public key
   - isValid = true

3. SQL EDITOR
   Jalankan UTUH satu kali:
   V15-INSTALL-SUPABASE-FINAL-AUDITED.sql
   Hasil verifikasi akhir harus seluruhnya ok=true.

4. AUTH TEST AWAL
   Untuk pengujian awal, Confirm Email boleh dimatikan sementara.
   Untuk produksi, aktifkan kembali setelah custom SMTP benar-benar teruji.

5. BUAT USER SUPER ADMIN
   Authentication > Users > Add user.
   Setelah user ada, jalankan:
   V15-SETUP-ADMIN-PERTAMA.sql
   Pastikan email pada SQL sesuai akun admin.
   Hasil harus role=super_admin dan active=true.

6. JALANKAN DIAGNOSTIK
   Jalankan V15-DIAGNOSTIK-SETELAH-INSTALASI.sql.
   Periksa tabel, fungsi, trigger, admin, paket, dan RLS.

7. JANGAN JALANKAN SEED _PAYMENT_CONFIG_ DENGAN durasi_hari=0
   Schema V15 mensyaratkan durasi_hari > 0.
   Installer sudah membuat _PAYMENT_CONFIG_ dengan durasi_hari=1 dan aktif=true agar dapat dibaca frontend.
   Atur bank/rekening/WhatsApp melalui Admin setelah login.

8. UPLOAD KE HOSTING
   Upload folder member/ beserta JS-nya. SQL hanya referensi dan tidak wajib dipublikasikan.
   Hard refresh Ctrl+F5.

9. UJI BERURUTAN
   a. /member/index.html terbuka.
   b. Daftar akun test -> profil pending tercipta.
   c. /member/admin.html -> login Super Admin berhasil.
   d. Admin melihat Pendaftaran Baru.
   e. Aktivasi paket -> member status aktif + masa aktif.
   f. Login member -> konten sesuai tahap/jenjang.
   g. Latihan -> jawaban/progress tercatat.
   h. Tryout -> attempt, timer, submit, skor tercatat.

JANGAN menyatakan sistem siap produksi sebelum a-h lulus pada domain produksi.
