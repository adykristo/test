CARA SETUP KLINIKFISIKAPKU — VERSI TERINTEGRASI
================================================

1. Baca BACA-DULU.txt.
2. Upload semua isi folder test-main/ ke root repository GitHub Pages.
3. Pasang code.gs sebagai versi baru Google Apps Script.
4. Admin dibuka melalui:
   https://klinikfisikapku.com/admin-dashboard-login.html
5. Petunjuk rinci, format Word, migrasi paket lama, dan pemeriksaan setelah
   deploy ada di PANDUAN-INTEGRASI-ADMIN-TRYOUT.md.

PENTING:
- admin.html memang menampilkan 404; gunakan admin-dashboard-login.html.
- Jangan unggah code.gs atau appscripts.json sebagai file publik website.
- Jangan pernah memasukkan token GitHub atau ADMIN_KEY ke JSON publik.
- Deploy Apps Script sebagai New version setelah mengganti code.gs.
