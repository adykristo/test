# Audit RPC Supabase V15 — 11 Oktober 2026

Sumber: CSV pengguna `Supabase Snippet Untitled query (48).csv` (22 fungsi, enam kolom metadata).

## Temuan
- Semua 22 RPC berstatus SECURITY DEFINER.
- 20 dari 22 RPC memiliki EXECUTE untuk role authenticated.
- `kf_submit_attempt` dan `kf_submit_attempt_v13_core` tidak dapat dieksekusi langsung oleh role authenticated.
- `kf_admin_grade_essay_v15`, `kf_admin_list_essay_v15`, `kf_get_final_score_v15` menggunakan `search_path=""`.
- Fungsi lain menggunakan `search_path=public` (satu `public, storage`).
- Semua fungsi admin yang dapat dipanggil authenticated **harus** melakukan validasi role/owner secara internal. Metadata tidak membuktikan validasi itu ada.
- Fungsi submit V13 public wrapper dan core internal tidak boleh diubah tanpa audit source dan pengujian regresi.
- Audit berikutnya: ambil definisi hanya fungsi penilaian/otorisasi terpilih (hindari membagikan secrets dalam function bodies) dan audit role grants. Jangan langsung mengubah RPC atau revoke tanpa menilai dependensi produksi.

## Query read-only audit source RPC terpilih
```sql
SELECT p.proname AS nama_fungsi,
       pg_get_function_identity_arguments(p.oid) AS parameter,
       pg_get_functiondef(p.oid) AS definisi
FROM pg_proc p
JOIN pg_namespace n ON n.oid=p.pronamespace
WHERE n.nspname='public'
  AND p.proname IN (
    'kf_is_admin','kf_admin_grade_essay_v15',
    'kf_admin_list_essay_v15','kf_get_final_score_v15',
    'kf_submit_attempt_v13','kf_submit_attempt_v13_core'
  )
ORDER BY p.proname;
```

**Catatan**: baca definisi terlebih dahulu untuk memastikan tidak ada credential/secret literal sebelum membagikan hasil.
