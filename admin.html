Halaman ini khusus untuk Sir Ady — jangan dibagikan link-nya ke orang lain.

1. Koneksi ke GitHub (isi sekali saja)

Token dibuat di GitHub: Settings → Developer settings → Fine-grained tokens → pilih repo ini → beri akses Contents: Read and write. Token hanya tersimpan di browser Sir Ady, tidak ikut ter-upload ke repo.

Tips: selalu klik "Test Koneksi" dulu sebelum upload soal. Kalau test-nya gagal dengan pesan "Gagal terhubung", coba matikan sementara ad-blocker/VPN di browser, atau coba di jaringan lain.

3. Hapus Soal

Menghapus soal akan menghapus gambar soal & gambar pembahasannya dari GitHub, dan langsung menghilangkan soal tsb dari daftar data/manifest-soal.json. Tindakan ini tidak bisa dibatalkan.

4. Kumpulan Soal OSN (Upload & Hapus File)

File yang diupload di sini otomatis muncul di halaman "Kumpulan Soal OSN" pada web utama, sesuai jenjang yang dipilih. Kalau nama file sama persis dengan file yang sudah ada, isinya akan ditimpa (update), bukan jadi duplikat.

1. Koneksi GitHub

Token disimpan hanya di browser kamu (localStorage), tidak dikirim ke mana pun selain GitHub API. Buat token di GitHub → Settings → Developer settings → Personal access tokens (Fine-grained atau Classic dengan scope repo).

Daftar Soal

Rumus matematika/fisika ditulis pakai LaTeX, diapit tanda dolar. Contoh: $v = \frac{1}{2}at^2$ untuk inline, atau $$F = ma$$ untuk rumus besar di baris sendiri.
