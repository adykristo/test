1. Koneksi ke GitHub (isi sekali saja)

Token dibuat di GitHub: Settings → Developer settings → Fine-grained tokens → pilih repo ini → beri akses Contents: Read and write. Token hanya tersimpan di browser Sir Ady, tidak ikut ter-upload ke repo.

Tips: selalu klik "Test Koneksi" dulu sebelum upload soal. Kalau test-nya gagal dengan pesan "Gagal terhubung", coba matikan sementara ad-blocker/VPN di browser, atau coba di jaringan lain.
