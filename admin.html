📝 Jawaban Esai — Koreksi Manual

Semua jawaban esai peserta dikumpulkan per paket, dikelompokkan per peserta seperti folder, supaya mudah dibuka & dikoreksi satu per satu.

1. Buka Folder Jawaban Esai

Menggunakan konfigurasi Apps Script & Kode Rahasia Admin yang sama dengan tab "⚙️ Admin Tryout" → bagian 5 (Unduh Hasil Tryout). Kalau belum diisi, isi dulu di sana lalu kembali ke sini.

2. Folder Peserta

Klik nama peserta untuk membuka/menutup jawabannya. Nilai & catatan otomatis tersimpan di browser ini setiap kali kamu klik "Simpan Koreksi", dan juga akan dicoba dikirim ke Apps Script (kalau endpoint simpanKoreksiEsai sudah kamu tambahkan di script-mu).

Belum ada folder dibuka. Pilih paket lalu klik "Buka Folder Jawaban Esai" di atas.

3. Penyimpanan File Jawaban Esai di GitHub

Tombol "⬆️ Upload ke GitHub" pada tiap jawaban esai (yang ada file PDF-nya) akan menyalin file itu ke repository GitHub kamu, sebagai arsip cadangan di luar Google Drive/Sheet. Fitur ini pakai koneksi GitHub yang sama dengan tab "⚙️ Admin Tryout" → bagian 1 — pastikan sudah diisi & disimpan di sana dulu.

File akan tersimpan di folder repo: data/jawaban-esai/<id-paket>/<no-ujian>_soal<nomor>.pdf. Kalau file dengan nama sama diupload ulang, file lama akan otomatis diperbarui (bukan duplikat).

Catatan: fitur ini hanya membaca kolom jawaban esai dari data yang dikembalikan Apps Script-mu. Kalau folder di atas kosong padahal peserta sudah mengumpulkan esai, kemungkinan Apps Script belum menyimpan teks/file esai ke kolom Sheet — tambahkan kolom seperti Esai 1 Teks, Esai 1 File, Esai 1 Link (atau kirim seluruh array jawabanEsai sebagai satu kolom JSON) di Apps Script kamu.
