# Cara Pakai Fitur Tryout Terpadu

Panduan instalasi dan format Word terbaru berada di
[`PANDUAN-INTEGRASI-ADMIN-TRYOUT.md`](PANDUAN-INTEGRASI-ADMIN-TRYOUT.md).

Ringkasnya: upload seluruh isi folder `test-main/` ke root GitHub Pages,
deploy `code.gs` sebagai versi baru di Google Apps Script, kemudian buka
`admin-dashboard-login.html`. Data lama tetap kompatibel; simpan ulang paket
lama satu kali agar skema kunci privat terbaru terisi lengkap.
